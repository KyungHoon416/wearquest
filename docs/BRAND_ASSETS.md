# Login logo assets

Local SVG files in dist/brand avoid runtime third-party image requests.
- Google: four-color G vector; branding reference https://developers.google.com/identity/branding-guidelines
- Naver, Apple: Simple Icons v16 SVG paths, https://cdn.jsdelivr.net/npm/simple-icons@v16/icons/naver.svg and https://cdn.jsdelivr.net/npm/simple-icons@v16/icons/apple.svg (CC0 package; brand trademarks remain with owners).
- Kakao: black speech-bubble login symbol.

These changes affect presentation only; authentication setup remains separate. Verify each provider’s current brand requirements before production release.
